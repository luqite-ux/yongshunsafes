# 首页媒体与采购路径

生成前规划；实际成品尚未生成。无视频点位，未授权使用视频。

负责人审美原话：网站设计风格参考 https://openai.com/index/gpt-6-astra/ 或 https://antigravity.google/，但是不要黑色调的。在制作时要灵活采用three.js脚本，不要弄那种死气沉沉的css出来。

全站采用浅色页面体系；原始 Banner 三张全部传给 v0 并采用。Banner 本身深蓝背景不能据此扩展成深色整站。原图主体不压暗，使用原始留白放置 DOM 文案；手机端单独安排焦点和文字，必要的明亮化处理必须保留原产品并形成可追溯派生资产，不能改产品结构。

联系页与首页询价区须包含真实公司简介、主营、地址、电话和正式邮箱；文案侧与表单侧按实际长度平衡，可采用上方公司信息加下方表单。表单字段含姓名、邮箱、公司、电话、系列/型号、数量及定制需求；每入口独立captchaScope，验证码与真实写入由Codex工程接入。

信任资料：旧站文字涉及3C与多项专利，分别按原文范围登记；目前未发现可逐张发布的认证扫描件，不生造认证图片。证书如后续发现，逐张独立上首页与内页。营业执照不得与产品认证混为一类。

全量接管：v0附件仅12项代表/必要素材。Codex必须回到source-catalogue、material-fact-manifest和产品身份清单，全量回填；所有产品图、企业图及场景图在业务页面逐项实显后才能终审通过。
