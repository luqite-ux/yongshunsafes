# 永顺动效方案

阶段：生成前设计方案；不是成品双端验收结果。遵循负责人“不黑色调、灵活采用 Three.js”的原始要求。对比已读近期鞋业与竹炭组合，本客户以保险柜锁闭路径和真实产品结构细节为行业差异，不照搬生产路径动画。

## 外部候选与采用决定

1. Motion 官方滚动触发与滚动关联方案：https://motion.dev/docs/react-scroll-animations 。已实际读取。采用逐区块真实进入视口的触发机制；不照搬其默认 opacity:0 示例，先保证基础 HTML 可见，再渐进增强。适合产品表、制造、FAQ 等内容。
2. Three.js 官方粗线条空间示例：https://threejs.org/examples/webgl_lines_fat.html 。已读取示例入口，尚未完成真实渲染审阅。只作为实现候选，拟采用浅色空间线条表达锁闭关系；不复制示例背景，也不将抽象线框伪称真实柜体三维模型。
3. 既有案例库 scroll-reveal 候选：animata:scroll-reveal；已通过原生 MCP 获取完整70文件包，packageHash b72aa888e5905683a48e81dd8d2dcefaaf843d31dd1f6c51a79e38fd9e42c10f，留存 scroll-reveal-package.json。真实源码使用 h-96 内部滚动、大量 h-32 占位与0.5初始文字透明度；不适合本客户自然页面滚动、移动阅读和对比度要求，故不挂载。采用逐区块原生视口生命周期的安全实现，不能声称该包已经复用或生产验证通过。
4. 淘汰连续 360° 产品旋转：没有客户真实三维模型，旋转平面图片不能证明产品结构；影响手机性能与识别。

## 四个场景

| ID | 职责与位置 | 实现与边界 | 手机/降级 |
|---|---|---|---|
| YS-M01 | 首页 Banner 标题、卖点、CTA 分层进入 | 三张指定 Banner 完整保留，文本是真实 DOM；切换只关联当前 slide | 390px 单独排版，减少位移；reduced-motion 手动切换、无自动播放 |
| YS-M02 | 全站区块、产品卡、表格、制造和案例逐项进入 | 每个元素独立 IntersectionObserver；入场500–700ms，20–28px；只有真正进视口才记录 played | 手机12–18px；无JS/失败正文立即可见，不标记为已播放 |
| YS-M03 | 产品图库、筛选、FAQ、导航、表单的操作反馈 | 选择图库更新主图；contain保持主体完整；筛选过渡不跳焦点；关闭导航可再次打开；提交状态真实 | 不依赖hover；键盘可用，触屏按钮足够大，reduced-motion即时变化 |
| YS-M04 | 首页锁闭结构或制造段的 Three.js 辅助空间图形 | 懒加载、视口内才requestAnimationFrame；抽象锁闭节点/轨迹，不改变客户产品。以真实照片为主，禁止装饰盖住主体 | 390px降低DPR/线段量，省流量或无WebGL用静态SVG同义表达；隐藏页暂停、卸载dispose |

## 生命周期验收计划

桌面及390px逐页覆盖首页、目录、全部详情、制造、案例、About、News、Contact。检查每页首/末主要区块、正常滚动、锚点跳转、返回与慢加载。顶部静置超过实现最长兜底时间后再滚到下方，必须仍触发对应区块；禁止15秒或全局超时提前完成离屏动画。

逐页验证正常JS、禁JS、动效脚本失败和慢加载，区分 fallback-visible 与 hasAnimated；reduced-motion不保留隐藏或位移。模板与完整内容分别留真实截图及动态观察，最终Production复验通过后才回写共享账本。
